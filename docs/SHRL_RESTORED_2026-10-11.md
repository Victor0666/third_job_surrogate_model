# SHRL 安全机制与参数恢复说明

当前代码按截图所列范围，将 SHRL 设置恢复为 `98a8ab4` 的三层安全机制；没有切换分支或回退提交。

| 项目 | 恢复后的行为或默认值 |
| --- | --- |
| Shield | 使用合法集合与预测安全集合的交集；纠正不安全动作；安全集合为空时采用确定性 fallback |
| Qc 的安全成本 | 正风险增量、实际 DDL 违反、归一化超时的加权和；Manager 使用阶段累计成本 |
| λ 初值 | 1.0 |
| λ 学习率 | 0.05 |
| 成本预算 | 0.01 |
| 安全模式能耗奖励缩放 | 0.001 |
| Host/VM 相对能耗观察 | 移除新增观察及对应维度扩展 |
| 能耗决策诊断 | 移除新增记录和聚合字段 |

动态 λ 仍由原有开关控制，开启后按 episode 违反率及 EMA 更新。密集安全成本用于 Qc 学习，两者保持恢复前原始三层实现的不同用途。未修改普通混合奖励的延迟权重。

保留后续 LLM 规则生成、模型接入、工件身份校验、统一通信模型以及独立对比算法的修改。工件使用 `dense_fuzzy_ddl_cost_v1`、`active_fuzzy_ddl_shield_v1`、`no_relative_energy_v1` 标识恢复后的语义，防止继续训练时误用监测模式数据。

需重新生成安全示范、离线预训练并在线训练。旧监测模式示范和检查点不能作为本设置下的有效训练结果；显式传入旧参数的命令也需同步更改为上述数值。
